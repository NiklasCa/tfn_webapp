# Gemini Agent Rules

1. **NEVER** commit or push changes to git without explicit command/permission from the user.
2. Always verify syntax before reporting task completion.
3. Always verify syntax before committing.
4. Use SemVer version numbering. YX.K.MN - Patch should use leading zero for numbers below 10, major version is allowed to have single digit - Y is only used as a prefix for major version 10 and above.
5. Always check all pending changes (git status/diff) before committing and include a summary of ALL changes in the commit message.
